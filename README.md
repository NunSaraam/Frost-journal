# 동토일지 — 혹한의 서른 날

혹한 속 좀비 사태에서 서른 날을 버티는 텍스트 기반 하드코어 생존 웹게임.
더 롱 다크의 생존 수치 관리와 60초!의 일지 연출을 합쳤다.

- **플레이:** `game/index.html` (브라우저에서 바로 실행, 설치 없음)
- **기획서:** `docs/동토일지_시스템기획서.pdf`
- **메인 페이지:** `index.html` (디오라마 + 동토일지)

## 조작 (HUD)

화면 전체가 펼친 일지 한 권이다.

- **왼쪽 장:** 날짜와 날씨, 산장 그림(내 상태와 가진 물건), 그날의 일지, 생존 수치 7개
- **오른쪽 장:** 행동 / 소지품 / 제작 / 도감 탭. 낮에는 행동력 3을 나눠 쓰고, 밤에는 불의 세기를 고른다.
- **작은 화면:** 하단 바에서 일지와 행동 메뉴로 바로 이동, 행동 메뉴 위에 상태 요약, 일지 접기 버튼
- 상단의 **숫자 보기**를 켜면 수치와 습격 확률이 숫자로 나온다.
- 진행은 브라우저에 자동 저장되며 표지에서 **이어서 쓰기**로 돌아온다.

## 한 사이클

아침 일지 → 낮 행동(탐색, 장작, 난로, 보수, 쉬기, 일지 쓰기, 먹고 마시기) → 탐색 이벤트 → 밤 불 선택 → 밤 판정 → 다음 날 아침.
30일을 버티거나 구조되면 엔딩(4종), 생존 수치가 무너지면 사망.

## 수정 내역 (11/18 피드백 반영)

1. 밤이 되면 예상 기온과 불 선택부터, 아침에는 새 날짜와 지난밤 결과부터 보이도록 화면 자동 이동
2. 작은 화면: 하단 빠른 이동 바, 행동 메뉴 위 상태 요약, 일지 접기, 먹고 마시기 바로가기
3. 산장 그림 평소/위험 비교(`docs/scene_compare.png`) 후 교체 범위 결정: 캐릭터 상태 그림 2장만 교체

검증: 난이도별 500판, 총 1,500판 자동 플레이에서 오류 0건, 모든 판 엔딩 도달.

## GitHub Pages로 공개하기

1. GitHub에서 **New repository** → 이름 입력 → **Public** 선택 → 만들기
2. **Add file › Upload files**로 이 폴더 안의 파일과 폴더를 모두 끌어 올리고 **Commit changes**
3. **Settings › Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 **Save**
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생긴다. 이 주소가 제출 링크다.
